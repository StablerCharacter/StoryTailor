---
title: Stages
description: The stages within a StoryTailor game
---

A StoryTailor game consists of various stages. They might be 
called "scenes" in other game engines. StoryTailor provides you 
with 3 pre-made scenes.

- [Main Menu](/StoryTailor/stages/main-menu-stage)
- [Story](/StoryTailor/stages/story-stage)
- [Credits](/StoryTailor/stages/credits-stage)

In the future, There will be a way to make custom scenes.
